GenerateAssetPackName(string)

Generates an asset pack name from an asset bundle name using the leaf folder plus an 8-char xxHash32 of the full parent path. e.g. "bundles/characters/hero" -> "characters_a1b2c3d4" Length stays bounded (leaf + 9 chars) so deeply nested bundle paths don't blow up Windows MAX_PATH during gradle build, and the hash disambiguates leaf-name collisions across different parent paths (e.g. "ui/icons" vs "menu/icons"). Leaf is sanitized independently (Google Play rules: must start with letter, only [a-zA-Z0-9_]) before the hash is appended, so the hash is never partially stripped even when the leaf is all-digits, leading-underscore, or non-ASCII (e.g. Korean folder names) — uniqueness is preserved by the hash regardless.
